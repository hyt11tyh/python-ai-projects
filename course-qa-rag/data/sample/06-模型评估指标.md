# 模型评估指标

## 分类问题的混淆矩阵

对二分类，可以把预测结果整理成混淆矩阵，包含四类计数：

- TP（真正例）：实际为正，预测也为正
- TN（真负例）：实际为负，预测也为负
- FP（假正例）：实际为负，预测却为正
- FN（假负例）：实际为正，预测却为负

许多分类指标都由这四个量组合而成。讨论“模型好不好”时，先分清你更不能接受假正例还是假负例。

## 准确率、精确率、召回率与 F1

- 准确率 Accuracy = (TP + TN) / 总数。类别极不平衡时，准确率容易误导。例如正类只占 1%，把所有样本都预测为负类也能得到 99% 的准确率，但这个模型毫无用处。
- 精确率 Precision = TP / (TP + FP)。它衡量“预测为正的样本里有多少真的是正类”，关注的是误报。
- 召回率 Recall = TP / (TP + FN)。它衡量“实际正类中有多少被找出来”，关注的是漏报。
- F1 分数是精确率与召回率的调和平均：F1 = 2 * P * R / (P + R)。当两者需要兼顾、又不希望被某一个极端值带偏时，F1 比单独看一个指标更全面。

## ROC 与 AUC

ROC 曲线以假正例率（FPR）为横轴、真正例率（TPR，也就是召回率）为纵轴，展示分类阈值变化时的权衡。AUC 是 ROC 曲线下的面积，越接近 1 表示模型把正负样本排得越开，排序质量越好。若正负样本比例变化较大，也可以同时关注精确率-召回率曲线（PR 曲线）。

## 回归指标

回归常用均方误差 MSE、均方根误差 RMSE 和平均绝对误差 MAE。RMSE 对大误差更敏感；MAE 更稳健，也更接近“平均错了多少”。选择哪一个，应与业务上更关心“偶尔出现很大错误”还是“平均偏差”保持一致。
