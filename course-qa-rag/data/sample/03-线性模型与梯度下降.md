# 线性模型与梯度下降

## 线性回归

线性回归假设目标值可以写成特征的加权和再加偏置：

ŷ = w₁x₁ + w₂x₂ + … + wₙxₙ + b

参数 w 和 b 通过最小化预测值与真实值之间的误差来学习。最常用的损失函数是均方误差（MSE）：

L = (1/N) Σ (ŷ_i - y_i)²

当特征之间近似线性无关时，最小二乘可以有解析解；特征很多或需要加正则时，更常见的做法是用迭代优化。

## 分类中的逻辑回归

逻辑回归用于二分类。它先计算线性得分，再经过 Sigmoid 函数把结果压到 (0, 1) 区间，解释为属于正类的概率。训练时通常最小化交叉熵损失，而不是直接最小化分类错误率，因为错误率不可导，难以用梯度方法优化。逻辑回归虽然名字里有“回归”，但解决的是分类问题。

## 梯度下降

当解析解不容易求，或数据量很大时，常用梯度下降及其变体来最小化损失。基本思想是：计算损失函数对参数的梯度，然后让参数沿负梯度方向更新：

θ ← θ - η ∇L(θ)

其中 η 是学习率。学习率过大可能导致损失震荡甚至发散，过小则收敛很慢。选择学习率是训练线性模型和神经网络时最常见的调参工作之一。

## 批量、随机与小批量

- 批量梯度下降：每次用全部训练样本计算梯度，更新方向稳定，但在大数据集上一次更新代价很高。
- 随机梯度下降（SGD）：每次只用一个样本，更新快但噪声大，损失曲线会抖动。
- 小批量梯度下降：每次用一个 batch（例如 32 或 64 个样本），是深度学习中的默认选择，能在稳定性和效率之间取得平衡。

实践中还会使用动量、Adam 等自适应方法来改善收敛，但入门时先理解“损失、梯度、学习率”三者的关系最为重要。
